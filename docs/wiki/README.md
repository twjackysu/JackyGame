## 新手三件事
1. 技能會自己放，你只管走位：**紅色／紫色的預告範圍**走出去，來不及就按閃避。**翻滾閃過攻擊**會回 6 MP（大招更快好）、閃避剩下的冷卻減半。
2. 升級後打開 ☰ → **技能樹**點技能；撿到裝備打開「行囊」換上。
3. 在**營火旁**休息、強化、找行商買賣。

## 地圖順序
1. **霧語森林**（Boss：霧角狼王，建議 Lv3）
2. **荊棘谷**（Boss：棘冠狼后，建議 Lv6）
3. **燼紅裂谷**（Boss：燼心岩王，建議 Lv10）
4. **星隕高原**（Boss：星骸守望者，建議 Lv14）——通關後開放
