# 01 市場調查與設計啟示

> 階段 0 研究成果（2026-10-23 第 1 輪）。網路搜尋結果品質有限，以下結合公開資料與既有業界知識整理，重點放在「對本作設計的啟示」。

## 1. 熱門手機 RPG 好玩在哪

| 作品類型 | 代表 | 玩家愛的點 | 本作可借鏡（不抄內容） |
|---|---|---|---|
| 回合制 + 即時判定 | 《光與影：33號遠征隊》(2025 年度話題)、紙片瑪利歐 | 回合制好上手，但閃避/格擋的時機判定讓「技巧」重要 | **回合制 + 時機輸入**，手機上一指就能操作 |
| 單機付費佳作 | Stardew Valley、Slay the Spire、Dead Cells、Grimvalor、Oceanhorn | 無廣告、無體力、離線、內容扎實 | 完全離線、無課金、短時段可玩 |
| 抽卡 RPG | 原神、崩鐵、FGO | 角色魅力、羈絆劇情、華麗大招演出 | **同伴魅力 + 大招演出（鏡頭/閃光/慢動作）** |
| 放置/卡牌 | Slay the Spire、Marvel Snap | 一局 2–5 分鐘、決策密度高 | 卡牌小遊戲一局 3–5 分鐘 |
| 敘事選擇 | 巫師 3、異塵餘生、極樂迪斯可 | 選擇有後果、技能檢定、多結局 | 技能/知識檢定、後果延遲回饋、多結局 |

**結論：** 手機上最被稱讚的單機 RPG 是「操作簡單但有判斷與時機」、「每次打開 5–15 分鐘就有進度」、「角色讓人想看下去」。

## 2. 轉生／追放／被當廢職業／遊戲知識無雙 套路分析
受歡迎的核心情緒：
1. **逆轉的爽快感**：被看不起 → 用別人不知道的知識證明自己。關鍵在「打臉」要有鋪陳與回收。
2. **資訊優勢的智力快感**：主角知道隱藏機制、Boss 弱點、隱藏寶箱。讀者/玩家享受「我知道而 NPC 不知道」。
3. **偏離劇本的懸念**：主角的介入讓世界偏離原作劇本，知識逐漸失效 → 後期產生緊張感（避免無雙到無聊）。
4. **被重新評價的廢職業**：冷門職業的隱藏玩法，給玩家「發掘 build」的樂趣。
5. **夥伴因主角而改變命運**：原作中會死/黑化的角色被救下，帶出情感線。

套路常見的弱點（我們要避免）：主角太無敵沒有挑戰、其他角色只是捧場工具人、打臉重複。
→ 本作對策：**「攻略筆記」是遊戲機制**（玩家真的能用知識拿優勢），但**「劇本偏移」**讓後半段知識會失準，同伴也有自己的主見與反對意見。

## 3. 手機 UX 慣例
- **直式單手**：拇指熱區在畫面下 1/3；主要按鈕放下方，資訊放上方。
- 點擊目標 ≥ 44pt（本作 720×1280 設計解析度下 ≥ 88px）。
- 每個畫面一個主要動作；返回固定在左上或下方。
- 對話：點任意處推進，長按快轉，可回看紀錄。
- 自動存檔且明確顯示（右上小圖示閃一下）。
- 中斷友善：隨時切出 App 都不丟進度（`visibilitychange` 時存檔）。
- 不要求精準拖曳；滑動手勢只用在「閃避」這種大範圍動作。
- 文字至少 28px（720 寬度），中文行距寬鬆。

## 4. 單機 RPG 的留存設計（無課金版本）
- **前 3 分鐘就要有爽點**：開場直接進入一場有演出的戰鬥（教學融入）。
- **短循環**：每 5–10 分鐘一個小目標（一場戰鬥、一段劇情、一局卡牌）。
- **中循環**：每 30–45 分鐘一個章節/Boss，解鎖新同伴或新系統。
- **長循環**：同伴羈絆、卡牌收集、隱藏職業技能樹、多結局 → 重玩動機。
- **好奇心勾子**：每章結尾留懸念；「攻略筆記」顯示 `???` 的未解鎖條目。
- **收集與完成度**：卡牌圖鑑、筆記完成度、羈絆事件數。

## 5. 卡牌小遊戲（昆特牌式）為何好玩
參考公開設計分析（gamedeveloper.com、PC Gamer〈The making of Gwent〉）：
- 三戰兩勝，**雙方都 pass 才結束該回合** → 「何時放手」本身就是策略。
- 手牌有限、抽牌稀少 → **卡牌優勢**是核心資源；第一回合過度投入會輸後面。
- 可以虛張聲勢、誘使對手交出關鍵牌。
- 規則一句話講得完，深度來自取捨。
→ 本作「燼牌」取這些**通用機制概念**，但牌面、陣營、名詞、規則細節全部原創（見 03）。

## 6. 選擇與後果（異塵餘生式）
- 技能檢定用**屬性 + 知識**，顯示成功率，失敗也有劇情（不是死路）。
- 後果延遲出現（第 1 章的選擇在第 3 章回收）比立即回饋更有記憶點。
- 多種解法：戰鬥 / 說服 / 潛行 / 用「攻略知識」。
- 陣營聲望影響商店、任務、結局。

## 7. 「第一眼驚艷」的手段（程式美術可達成）
- 強烈配色（深藍紫夜空 + 琥珀火光），光暈與粒子。
- 鏡頭：大招時拉近 + 慢動作 + 色差/閃白，命中停頓（hit-stop 60–120ms）。
- 剪影角色 + 邊緣光（rim light），讓風格「刻意」而非「沒素材」。
- UI 動效：所有面板用彈性補間進出場。
