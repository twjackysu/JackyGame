# 05 美術與音效

> 限制：沒有 AI 繪圖、不能用版權素材。策略：**把「程式生成」變成風格**——剪影 + 光。

## 1. 美術風格：「星燼剪影（Ember Silhouette）」
- 角色、怪物、場景前景都是**深色剪影**，靠**邊緣光（rim light）**、**發光眼睛/武器**、**粒子**表現。
- 背景是**多層視差漸層**：天空漸層 → 遠山 → 中景 → 前景剪影，加上霧與光束。
- 第一眼印象參考：剪影風平台遊戲、皮影戲、舞台燈光；大量**光暈（bloom/glow）**。
- 標題畫面（已完成第一版）就是此風格的樣板。

## 2. 色彩
| 用途 | 色 |
|---|---|
| 夜空深 | `#0b0f1e` → `#2a1650` |
| 星燼琥珀（主角/友方光） | `#ffb347`、`#ffd98a` |
| 蝕化紫（敵方） | `#8a2be2`、`#c04dff` |
| 危險紅（不可格擋） | `#ff3b3b` |
| 可格擋白 | `#f4f1ff` |
| UI 文字 | `#f5ecd7`（米白），次要 `#a89cc8` |
| UI 面板 | `rgba(16,12,34,0.82)` + 1px `#ffb34755` 描邊 |
- 每個區域一個主色調：灰燈鎮（琥珀/藍）、霧語森林（青綠/白霧）、礦坑（鐵鏽/銅）、王都（金/藍白）、裂谷（紫/黑/星白）。

## 3. 角色呈現
- **戰鬥/探索**：向量剪影（Phaser Graphics 畫成 texture），每位角色有辨識度的輪廓：
  - 連恩：長外套、手提燈（燈會發光、粒子）。
  - 瑟琳：馬尾、長劍、披風。
  - 莉歐拉：大護目鏡、背包管線、蓬鬆短髮。
  - 伊歐：長白髮（發光）、無鞋、周圍漂浮光點。
  - 洛克：寬肩、大斗篷、斧槍。
- **骨架式動畫**：角色由多個部件（頭、身、手臂、武器）組成 Container，用補間做待機呼吸、攻擊揮擊、受擊後仰。
- **對話立繪**：上半身剪影 + 邊緣光 + 角色色調背景；表情用眼睛光與符號（！、…、♪）表達。

## 4. 特效（game feel 清單）
- **命中**：hit-stop（60–120ms）、鏡頭震動（強度依傷害）、白閃（目標 tint）、火花粒子、傷害數字彈跳。
- **完美判定**：慢動作 0.2s、金色衝擊環、「PERFECT」大字縮放、更高音效。
- **共鳴引爆**：畫面暗下 → 燈印依序亮起（音階上升）→ 光柱 + 衝擊波 + 色差 + 鏡頭拉遠再拉回。
- **破防**：玻璃碎裂粒子 + 「BREAK」字 + 敵人跪地動畫。
- **UI**：按鈕按下縮 0.94 + 回彈；面板 Back.Out 進場；數字滾動。
- **PostFX**（WebGL）：bloom/glow、vignette、局部 barrel 扭曲（大招）。低階裝置可在設定中關閉（「畫質：高/低」）。

## 5. 字型
- 不打包大型中文字型（太大）。使用系統字：`"Noto Serif TC", "Songti TC", "PingFang TC", "Microsoft JhengHei", serif` 作標題，sans-serif 作內文。
- 標題類大字可用 Graphics 描邊 + glow 強化。

## 6. 音效（WebAudio 程序生成）
- `src/audio/sfx.ts` 已有類 ZzFX 合成器；擴充成**音效表**（具名預設）：
  - `ui_tap`、`ui_confirm`、`ui_cancel`
  - `hit_light`、`hit_heavy`、`perfect`、`parry`、`dodge`、`break`
  - `lamp_place`（每盞音高遞增：C-E-G-B-D）、`resonance`
  - `card_play`、`card_pass`、`round_win`
  - `levelup`、`item_get`、`save`
- 混音：所有 SFX 過一個 master gain + 簡單 compressor，避免爆音。

## 7. 背景音樂（程序生成）
- 自寫小型音序器：和弦進行 + 琶音 + pad + 低音，以 WebAudio oscillator + filter + 簡單 reverb（convolver 用生成的 noise impulse）。
- 曲目（各 30–60 秒 loop）：
  - 標題：慢板、D 小調、琶音 + 長 pad（神秘、史詩）。
  - 城鎮：溫暖大調、輕快撥弦。
  - 森林探索：五聲音階、笛聲感（正弦 + vibrato）。
  - 戰鬥：120 BPM、低音推進、打擊（noise + envelope）。
  - Boss：140 BPM、小調、加強打擊。
  - 酒館（燼牌）：搖擺節奏、鍵盤感。
  - 伊歐的旋律（主題動機）：5 音動機，貫穿全作，在關鍵劇情變奏。
- 音量設定：BGM / SFX 分開。
