## 題目 1：怎麼留住玩家（2026-10-24）
對話：<https://chatgpt.com/c/6adc982b-a324-83ee-8061-26825af104cd>

### 核心論點
- 最大賣點不是戰鬥、裝備或戀愛，而是設定本身：**「我知道劇本，但越想改變命運，攻略就越失準」**。所有系統都該回饋這個主題（照顧瑟琳 → 解鎖救她的新方法；研究燼牌 → 發現筆記沒有的情報；研究燈印 → 解鎖原作沒有的解法）。
- 4 個動機循環：改寫命運（筆記、偏移值）、掌握力量（燈印、技能樹）、建立關係（羈絆、營火、約會）、探索未知（探索、燼牌、隱藏事件）。
- 主線只有約 5 小時，**不要靠刷材料、刷好感拉長時間**；目標是五小時精彩故事加通關後想推薦朋友。一週目 5h、二週目 2–3h、集齊結局合計約 10–15h。
- 系統偏多：核心循環固定為「探索 → 發現命運情報 → 做選擇 → 戰鬥或事件 → 世界變化 → 筆記更新」，其他系統服務這個循環。
- 好結局的條件不要讓玩家非查攻略不可（不要藏在「好感 ≥ 65 且偏移值 ≤ 43」這種數值後面），要轉成可調查的線索。
- 先做 30–45 分鐘垂直切片驗證，成功標準：玩完第一句話是「瑟琳到底能不能救？」。

## 題目 1b：離線單機的長尾刷寶與配裝系統（2026-10-24，簡報已更正目標）
同一個對話（續問）：<https://chatgpt.com/c/6adc982b-a324-83ee-8061-26825af104cd>
定位：**暗黑的隨機裝備 × RO 的流派構築 × 天堂的稀有掉落 × 命運偏移**。總時數目標：主線 0–5h、初期刷寶 5–10h、中期 10–15h、高階深淵 15–20h、Build 研究 20–25h、終局收藏 25–30h+。

### 刷寶為什麼上癮，離線怎麼補
六要素：隨機驚喜、角色成長、Build 研究、稀有收藏、挑戰突破、效率優化。核心循環是「刷裝 → 改 Build → 挑戰更高難度 → 刷到更好的裝 → 再改 Build」。
離線版替代「多人比較、交易」：
- **個人紀錄取代排行榜**：最高層數、最短回合、最高單次共鳴傷害、無傷通關、使用的 Build。
- **Build 圖鑑取代社群攻略**：發現新組合時攻略筆記記錄（「已發現關鍵裝備 2/4」），不一次公開最佳解。
- **收藏室取代交易價值**：傳說、神級、套裝、特殊 Boss、隱藏 Build 展示，可產生配置卡片分享（不需伺服器）。

### 核心玩法：星燼深淵（主線通關後解鎖）
- 一場 5 到 10 分鐘，5 個房間（戰鬥、事件或寶箱、精英、Boss）從模板抽取，重用現有地圖與敵人，不做大型程序生成地圖。
- 主題「失落的命運」：瑟琳死去的世界、洛克沒背叛的世界、騎士團覆滅的世界、伊歐從未被刪除的世界。
- **深淵變異詞綴**（每場抽 1–3 個）：暗潮蔓延、星燼暴走、時序錯亂、無光之夜、命運逆轉、星火祝福。
- 難度 50 層：1–10 稀有、11–20 史詩、21–30 傳說、31–40 高品質傳說、41–50 神級。50 層後無限層，但**裝備不再升級**，只給紀錄、外觀、收藏。
- 增加戰鬥規則變化（敵人交換位置、Boss 吸收燈印、禁用特定技能、反彈完美格擋），不只是加血加攻，避免無聊。

### 裝備
- **6 格**：武器、防具、頭飾、飾品 ×2、**星燼核心**（改變戰鬥機制，例如「永燃之心」：火燈印不會消失，但每回合失去 3% 生命）。
- **6 階稀有度**：普通、魔法、稀有、史詩、傳說（固定效果加隨機詞綴）、神級（固定神級效果改變核心機制）。傳說與神級要「改變玩法」，不只是數值更高；神級不全面碾壓傳說（傳說適合速刷、神級適合高難度）。
- 詞綴：混合制。普通到史詩全隨機；傳說固定特殊效果加隨機一般詞綴；神級固定神級能力加隨機次要詞綴。使用詞綴池、依裝備類型限定、互斥群組。
- 套裝只做 2 件、3 件，效果要「新玩法」而非單純加數值（例：星火守望者、失落星衛、蝕星使徒）。
- 掉落：Boss 必掉一件主裝備，稀有 45%／史詩 35%／傳說 18%／神級 2%（初始值，待測）；**軟保底**（10 場無傳說逐步加機率）、**硬保底**（40 場無神級必掉）；重複神級分解成「神格碎片」，20 個可指定製作已解鎖的神級。保底要包裝成世界觀裡的「星燼凝聚」，不要像抽卡。
- 強化：**必定成功**（不做天堂式爆裝，因為離線沒有補救），最高 +10，高階需要更多材料；詞綴重鑄可鎖定其他詞綴，成本遞增並設上限。材料控制在 5 到 7 種，所有裝備可分解。

### Build 深度
掌燈人六大流派：**星火爆發**（累積後引爆）、**永燃持續**、**完美格擋**（格擋生成燈印）、**共鳴連鎖**（共鳴後重生燈印）、**蝕星風險**（犧牲生命換傷害）、**時序控制**（伊歐倒帶）。
關鍵手法：**同一個技能在不同裝備下產生不同效果**（例如「點燃燈印」搭永燃之心不消失、搭初火之燈給共鳴能量、搭蝕星核心耗 5% 生命生成兩個），用少量技能產生大量玩法。同伴每人先做兩條流派，隊伍組合也是研究對象。

### 與劇情串連
- **偏移值決定掉落池**：低偏移出騎士團裝備、中偏移失落歷史、高偏移蝕星裝備、極高偏移「不存在的神級裝備」。**通關後深淵用獨立的「殘響偏移值」**，玩家可自由調，不必為了裝備破壞主線結局。
- **同伴專屬傳說**：瑟琳「未折之誓」（連恩低血時替他擋致命一擊）、莉歐拉「自由鍊金手札」、伊歐「遺忘的時針」（倒帶後下次共鳴不耗燈印）、洛克「老兵的最後一枚硬幣」。
- **攻略筆記記錄 Build**：流派圖鑑、已發現關鍵裝備、最高傷害、最高層數；裝備詳情會推薦「下一個目標」（套裝缺哪件、在哪個深淵取得），玩家可追蹤一個目標。
- **燼牌刻印**：擊敗特殊牌手得刻印（滿月、殘月），可裝備提供戰鬥效果；但要提供替代取得途徑，不強迫精通燼牌。

### 要避免的坑（ChatGPT 的對策）
1. **數值膨脹**：裝備基礎數值有上限，50 層後不加等級，高階裝備給機制不給倍率；暴擊、冷卻縮減設上限；傷害加成多用加法。目標是終盤強 Build 比普通 Build 強數倍，而非數萬倍。
2. **Build 失衡／無限循環**：統一效果觸發系統（OnAttack、OnCritical、OnBlock、OnMarkCreated、OnResonance、OnEnemyKilled），每個效果有觸發條件、冷卻、每回合上限、是否允許連鎖；裝備效果產生的額外共鳴預設不能再次觸發同一件裝備的共鳴效果。
3. **重複變無聊**：深淵加規則變化而不只加數值。
4. **手機 UI**：三層資訊（列表只顯示名稱、稀有度、評分、特殊效果圖示；詳情顯示完整詞綴；比較模式只顯示差異）；一鍵分解低稀有度、自動鎖傳說以上、Build 預設存檔；不單靠評分判斷好壞。
5. **改存檔**：做基本完整性檢查與備份即可，離線沒有排行榜與交易，不值得投入反作弊。

### ChatGPT 的優先順序
1. **資料驅動的裝備／詞綴／效果引擎**（所有長尾內容的基礎，沒有它每新增一件特殊裝備就多一份維護成本）
2. **燈印共鳴與裝備效果的 Build 深度**（先讓 3 種流派真的好玩再擴到 6 種）
3. **可重複挑戰的星燼深淵與目標掉落**
評估指標：「玩家取得第一套完整 Build 後，會不會主動想研究第二套？」

### Claude 評註
- **同意方向**，而且它與現有架構相容：效果觸發框架可以掛在現有戰鬥事件上，`src/core/sim/` 已有戰鬥模擬器可以擴充成 Build 批次測試（這是整套系統最重要的安全網）。
- **前提差異**：ChatGPT 假設燈印有火、風、光、盾、暗、時等多種類，但目前遊戲的燈印只有一種。若採用，要先決定要不要加「燈印種類」，這會影響技能樹、敵人弱點與戰鬥 UI；建議由 Jacky 決定，或先用「同一種燈印、不同觸發效果」的方式做最小版。
- **現有設計會被改動**：裝備欄從 3 格變 6 格、`MemberState.equipment` 的資料結構、掉落與商店、存檔格式都要擴充；手機直式的裝備比較 UI 是最大的 UI 工程。
- **內容量**：完整版的數量對手工是不可能的，必須由資料表加程式規則生成（詞綴池 × 模板），再由 AI 批量產出名稱與敘述。
- **美術**：裝備圖示已有 `sheet_gear`，每件傳說以上若要獨立圖示，Gemini 額度會成為瓶頸；詞綴裝備建議用「模板圖示 + 稀有度外框與顏色」。
- 它的 2% 神級與保底數字只是起點，必須用模擬器校準。
- 它把裝備強化設計成「必成功」，我同意（離線沒有交易，爆裝只會逼玩家讀檔）。
- 提醒：保底與掉落機制若做得像抽卡手遊，可能影響「全年齡、免費、無內購」的觀感，建議保留 ChatGPT「星燼凝聚」的世界觀包裝。
