# 11 自由探索 RPG 改版（Jacky 10/24 指示，**最高優先方向**）

> Jacky 10/24 13:30 試玩後的回饋：「玩法還是有點枯燥。希望像以前的電腦 RPG 一樣**自由走動探險**，碰到某些人物或場景才觸發劇情，其餘都讓玩家很自由：**自由買賣裝備道具、自由點技能搭配、自由發展戀愛路線**。之後每一輪 loop 都要朝這個方向。」
> 本文件取代 D-002（節點地圖）。所有開發迴圈在選工作時，以本文件的里程碑為主線；舊 NEXT 裡的打磨項目只在里程碑之間的空檔做。

## 1. 目標體驗
- 打開遊戲 → 一個**可以走的城鎮**：角色在街上走、跟路人說話、進商店、進酒館打燼牌、出城到森林。
- 主線不再是「點節點 → 看對話」，而是「走到某人／某地 → 觸發劇情」。頭上有「！」的 NPC 推進主線，「？」是支線。
- 玩家可以**不推主線**，去打怪練功、賺錢買裝備、找寶箱、點技能、陪同伴聊天約會。
- 手機直式單手：**點地面就走過去**（自動尋路），按住拖曳出現**虛擬搖桿**；點 NPC／物件會走過去並互動。

## 2. 系統
### 2.1 探索（ExploreScene，新場景）
- 俯視 2D 格子地圖，格子 48px（720 寬約 15 格），地圖可大於畫面，鏡頭平滑跟隨。
- **地圖資料用 ASCII 字串撰寫**（`src/data/areas/*.ts`）：每個字元對應一種地塊（`.` 草地、`#` 牆、`~` 水、`T` 樹、`=` 路、`D` 門…），另列 `entities`（NPC、寶箱、告示、傳送點、觸發區、敵人）。這樣迴圈可以快速寫新地圖、也好測試。
- 碰撞、A* 尋路（點擊移動）、虛擬搖桿、同伴跟在後面（貪食蛇隊列）、門／出口切換地圖（淡出淡入）。
- 實體互動：`talk`（跑現有 DialogueRunner 劇本節點）、`chest`（一次性，旗標記錄）、`shop`、`inn`（回復＋存檔）、`sign`、`warp`、`trigger`（踩到觸發劇情，可設 `requires` 條件，用現有 `check()`）。
- NPC 頭上標記：主線「！」（金）、支線「？」（藍）、可聊天「…」。NPC 可小範圍閒晃。
- **引路之光**（連恩的招牌能力）在探索中也能用：照亮隱藏通路、看見隱形寶箱、揭示弱點——讓前世知識在地圖上也有用。
- 存檔記錄目前地圖與座標；自動存檔照舊（進出地圖、戰鬥後）。

### 2.2 世界與章節
- **現有章節節點地圖保留為「世界地圖／快速旅行」**：每個節點變成一個可走的區域（城鎮、森林、礦坑…），已去過的區域可快速旅行。
- 主線劇本（`src/data/dialogue/ch*.ts`）**盡量重用**：原本「地圖節點 → 劇本入口」改成「區域內的 NPC／觸發區 → 同一個劇本入口」。章節推進條件仍用現有旗標。
- 每章至少：1 個城鎮或據點 + 1 個野外／地城；每個區域 2–4 個支線或探索獎勵（寶箱、隱藏通道、燼牌對手、羈絆事件）。

### 2.3 戰鬥遭遇
- **明雷**：敵人在地圖上看得到（Q 版或剪影小怪），會巡邏，靠近會追；碰到 → 進現有 BattleScene → 回到原地。打倒的敵人在離開區域後重生。不做暗雷（隨機遇敵）。
- 背後偷襲（從敵人背後碰到）＝我方先攻；被追上＝敵方先攻。
- 有等級差時小怪會逃（減少無聊重複戰）。

### 2.4 經濟、裝備、道具
- 裝備欄：武器／防具／飾品（`MemberState.equipment` 已有欄位）。每件有數值（ATK/DEF/HP/速度/特效），在 BattleScene 生效。
- 商店：每個城鎮不同貨色，**可買可賣**（賣價 50%）。寶箱、敵人掉落、支線獎勵提供稀有裝備。
- 選單（探索中右上 ☰）：道具、裝備、技能、羈絆、任務日誌、燼牌收藏、設定、存檔。

### 2.4b 稀有掉落（Jacky 10/24 17:30 指示，D-049）
> 「有些稀有或神級裝備道具不能買到，但可以透過推 BOSS 或打小怪低機率打到。」
- 裝備分階：**普通**（商店買得到）／**稀有**（藍光，只能掉落或寶箱）／**神級**（金光＋專屬特效，只能掉落）。稀有、神級在資料表標 `rarity`，`price` 只用來算賣價，**商店不上架**（加測試保證）。
- 掉落表 `src/data/drops.ts`：遭遇 id → `[{ item, chance }]`。小怪：稀有約 3–5%、神級約 0.5–1%（每章一兩件，綁該區怪物）。Boss：**第一次擊敗必掉 1 件稀有**＋小機率神級；重戰（敗北重來不算）也有機率。
- 掉落演出要「爽」：勝利畫面卡片翻開、稀有藍色光柱、神級金色光柱＋震動＋專屬音效；背包裡稀有／神級名稱上色、圖示加光暈。
- 神級裝備要有**特效**而不只數值（例：開場燈印 +1、完美判定窗口 +15%、每回合回 1 SP、倒地時以 1 HP 撐住一次）——引擎 `createBattle` 收 `perks`。
- 圖鑑：行囊加「收藏」頁顯示已取得／未取得（剪影＋「？？？・掉落自：狼王」提示），給玩家去刷的動機。

### 2.5 技能樹（v2：前置與門檻，Jacky 10/24 17:30 指示，D-049）
> 「設計個技能樹，有些技能有前置的技能要先點多少，才能有更強大的技能。」
- 每位角色 2–3 條分支，每條 5–7 個節點，畫成**真正的樹**（節點＋連線，可分岔）。
- **前置條件**兩種，可同時要求：①前置節點（可多個，例：「需要 劍勢 Lv3 ＋ 疾步」）②**分支投入點數門檻**（例：「破陣分支已投入 8 點」）。終極節點可跨分支（兩條分支各 6 點）。
- **多等級節點**：被動節點 1–3 級（每級一點，效果疊加），讓「先點多少」有意義。
- **強大技能放在深處**：每條分支底部是一個**新的主動技能**（引擎新增技能 id 與效果），例：連恩「千燈共鳴」（全體燈印＋共鳴）、瑟琳「破曉一閃」（無視防禦）、莉歐拉「連鎖大爆破」、伊歐「星之搖籃曲」（全體回復＋淨化）、洛克「梭哈」（賭一把：高倍率或自傷）。
- 點數：每升一級 +1，Boss 首殺 +1（額外動機）。重置：營火免費（不在營火要花金幣）。
- UI：可上下捲動的樹狀圖；鎖住的節點顯示「需要：xxx Lv2／此分支 8 點（目前 5）」。
- 戰鬥技能槽：主動技能多了以後，每人最多帶 4 個（行囊「技能」頁勾選）。

### 2.6 戀愛與羈絆（全年齡、品味得體）
- 同伴好感不再只靠劇情：**營火／旅店可隨時找同伴聊天**（話題隨好感解鎖，一天一次）、**送禮**（每人喜好不同）、**城鎮約會事件**（夜晚在特定地點觸發）。
- 羈絆事件改成「好感達門檻＋到指定地點」就能觸發，而不是綁死章節。心之約定（告白）仍三選一。
- 同伴會對玩家的選擇有反應（既有設計），在地圖上跟隨的同伴偶爾冒出對話泡泡。

## 3. 美術
- 地塊：程式生成（canvas 畫草地、石板、木地板、牆、屋頂、水面動畫、樹），或使用**授權明確的 CC0 圖塊**（例如 Kenney 的 CC0 素材若能從 npm／GitHub 取得），記在 `docs/CREDITS.md`。
- 角色在地圖上：用 Jacky 的 Q 版圖（`public/art/hero_*.webp`）縮到約 64–80px，走路時上下彈跳＋左右翻轉；NPC 用程式 Q 版或請 Jacky 補圖（`docs/ART_PROMPTS.md` 加地圖用 NPC prompt）。
- 保持現有 game feel：粒子、光暈、燈火照明（夜晚地圖用遮罩做提燈光圈，很適合「掌燈人」主題）。

## 5. 給開發迴圈的規則
- `main` 永遠要能從頭玩到結局：新探索系統上線前，節點地圖流程保持可用；某章改完可走區域並通過機器人後，才把該章入口切過去。
- 地圖、NPC、商店、裝備、技能樹都**資料化**（`src/data/`），引擎與內容分開，方便每輪加內容。
- 每個新系統都要有 vitest（尋路、碰撞、商店買賣、裝備數值、技能點）與 Playwright 截圖檢查。
- 通關機器人（`scripts/playthrough.mjs`）要跟著更新：探索場景提供除錯 API（例：`__explore.goto(entityId)` 直接走到目標並互動），讓機器人能全程跑。
- 每完成一個里程碑問一次「這好玩嗎？」：走起來順不順、有沒有想探索的東西、錢和裝備有沒有讓人想去打怪。
