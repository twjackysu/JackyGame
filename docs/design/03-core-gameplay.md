# 03 核心玩法

> 設計原則：**一根拇指就能玩、但高手明顯打得更好**；每一個輸入都要有華麗回饋。

## 0. 畫面方向：直式（Portrait）— 已決定
- 設計解析度 720×1280（9:16），`Scale.FIT`。理由見 DECISIONS D-003：單手、通勤短時段、對話與卡牌都適合直式。

## 1. 遊戲循環
- **短循環（1–5 分）**：探索一個地點 → 對話/檢定 → 戰鬥或燼牌 → 戰利品。
- **中循環（20–40 分）**：一個章節區域：主線任務 + 2–4 支線 + Boss + 羈絆事件。
- **長循環**：同伴羈絆、掌燈人技能樹、燼牌收集、聲望、偏移值 → 多結局。

## 2. 探索
- **區域地圖（節點式）**：每個區域是一張手繪風（程式生成）的地圖，地點是可點擊的節點，節點間有路徑；移動時有角色剪影沿路徑走的動畫。適合手機、開發成本可控。
- **地點畫面**：視差背景 + 可互動熱點（NPC、寶箱、出口、調查點）。點熱點觸發對話/事件/戰鬥。
- **引路之光**：主角技能，在地點畫面長按 → 光波掃過，揭露隱藏熱點（隱藏寶箱、密道）。攻略筆記會提示「這裡有東西」。
- **隨機遭遇**：節點間移動有機率遭遇（可在設定調低）；區域清完 Boss 後遭遇降低。
- **營火**：每區域 1–2 個，回滿 HP、觸發羈絆事件、存檔點（雖然一直自動存檔，但營火是儀式感與羈絆觸發點）。

## 3. 戰鬥：「星燼時機戰鬥」
回合制 + 時機輸入（參考類型：回合制 RPG 的 action command / 格擋判定），**不使用任何作品的具體系統名稱或 UI**。

### 3.1 陣容
- 我方最多 3 人上場（主角 + 2 同伴），敵方 1–5 隻。
- 速度決定行動順序，畫面上方顯示**行動順序條**（頭像排隊）。

### 3.2 我方回合
1. 選擇行動：**攻擊 / 技能 / 道具 / 防禦**（下方 4 個大按鈕，技能另開面板）。
2. 選目標（點敵人）。
3. **時機輸入**：攻擊動畫中出現縮小的光環，光環與目標圈重合時點擊：
   - **完美（Perfect）**：±60ms，傷害 ×1.5，+2 星燼，hit-stop 100ms + 震動 + 金色粒子。
   - **良好（Good）**：±150ms，×1.15，+1 星燼。
   - **失誤**：×0.85。
   - 部分技能是連打（快速點擊計數）或長按蓄力放開（時機）。
   - 設定可開「自動時機」（固定算 Good），照顧輕度玩家。

### 3.3 敵方回合（防守時機）
- 敵人攻擊有**預兆動畫**（蓄力閃光，顏色代表類型）：
  - **白光** = 可格擋：命中瞬間**點擊** → 格擋成功傷害 -70%；**完美格擋**（±80ms）傷害 0 並**反擊**。
  - **紅光** = 無法格擋，只能閃避：**向任意方向滑動** → 閃避成功傷害 0。
  - **紫光** = 蝕化攻擊：必須**引路之光**（長按）才能抵消，否則附加「蝕化」狀態。
- 這是「簡單但吃技巧」的核心：輸入只有 點／滑／長按 三種，但需要讀預兆。

### 3.4 資源
- **HP**、**SP**（技能消耗，每回合 +1）。
- **星燼（Ember）**：全隊共用，上限 10。完美輸入、擊破弱點獲得。用來放**燈印技能**與**終結技**。
- **破防（Break）**：敵人有破防條，命中弱點屬性削減；破防後敵人跳過一回合且受傷 ×1.5 → 給玩家「找弱點」的動機（攻略筆記會直接告訴你弱點 = 知識無雙）。

### 3.5 掌燈人的隱藏機制（主角）
- **燈印**（1 星燼）：對敵人放置燈印（最多 5 盞，可疊在同一敵人上）。燈印每回合讓目標受到少量灼傷。
- **共鳴**（3 星燼）：引爆所有燈印。傷害 = `燈數 × 40% ATK × (1 + 0.15 × (燈數 − 1))`（燈愈多單燈愈強，1 盞 0.4×、5 盞 3.2× ATK），5 盞時有全畫面演出（慢動作 + 光柱 + 鏡頭拉遠）。
- **引路**（被動/主動）：顯示敵人弱點；主動施放時為同伴下回合攻擊 +30%。
- 讓「廢職業」的爽感在戰鬥中被實際感受到：佈局 → 一口氣引爆。

### 3.6 同伴技能（每人 4 招，隨羈絆解鎖第 5 招終極技）
| 角色 | 定位 | 招式例 |
|---|---|---|
| 瑟琳 | 前排輸出 | 逆風斬（完美時追加一擊）、守誓架勢（下次格擋必完美）、破陣突刺（破防大） |
| 莉歐拉 | 範圍/異常 | 星燼雷管（範圍+燃燒）、黏液瓶（減速）、過載（自傷換大爆炸） |
| 伊歐 | 支援 | 微光之歌（治療）、靜默（解除增益）、**回溯**（每場一次，撤銷敵人上一次行動） |
| 洛克 | 坦克 | 挑釁、反擊架勢、老兵的直覺（看穿下一次攻擊類型） |
- **連攜技**：特定兩人都在場且星燼 ≥ 5 → 合體技（演出最華麗的部分）。

### 3.7 戰鬥節奏目標
- 雜魚戰 45–90 秒；Boss 戰 3–6 分鐘，有 2–3 階段，每階段換攻擊模式與演出。
- 戰鬥加速 ×2 按鈕。
- 戰敗：可「從戰鬥前重試」，無懲罰（手機友善）。

## 4. 成長
- **等級 1–20**（全遊戲約 5 小時到 18–20 級）。升級：HP/ATK/DEF/SPD 固定成長 + 1 點**屬性點**。
- **屬性（用於檢定與戰鬥）**：
  - **力（STR）**：物理傷害、威嚇檢定
  - **敏（AGI）**：速度、閃避判定窗口 +、潛行檢定
  - **智（INT）**：技能傷害、調查/鍊金檢定
  - **魅（CHA）**：說服、商店折扣、羈絆增益
- **掌燈人技能樹**：3 條分支（燈印 / 共鳴 / 引路），共 15 節點，用「傳承碎片」解鎖（主線 + 探索取得）。
- **裝備**：武器、防具、飾品各 1 格。飾品帶特殊效果（例：完美判定窗口 +20ms）。不做複雜的隨機詞綴。
- **攻略筆記（Codex）**：收集型系統，條目分為 敵人弱點／隱藏寶箱／事件分歧／角色命運。部分條目一開始就有（前世記憶），隨偏移值變成「⚠ 可能失準」。

## 5. 選擇與後果（Fallout 式）
- **檢定**：對話選項標示 `[魅 6] 說服` 或 `[筆記] 「我知道你藏了什麼」`。
  - 屬性檢定：成功率 = clamp(50% + (屬性 − 難度) × 12%, 5%, 95%)，顯示百分比，擲骰有動畫。
  - **筆記選項**：擁有對應攻略筆記條目時，必定成功（知識無雙），但**提高偏移值**（+3~+10）。偏移值高 → 後期情報失準、但也解鎖最佳結局的條件。這是一個有趣的取捨。
- **旗標（flags）**：所有選擇寫入旗標，後續章節讀取。目標：每章至少 2 個「延遲回收」的後果（例：序章幫助的雜貨商，在第 3 章王都替你作證）。
- **聲望**：4 勢力 −100 ~ +100，影響商店價格、任務可接、部分結局。
- **多解法任務**：每個主要任務至少 2 種解法（戰鬥 / 說服 / 筆記 / 潛行或道具）。

## 6. 燼牌（Ember Cards）卡牌小遊戲
世界內的酒館遊戲。目標：一局 3–5 分鐘，規則 30 秒教完。

### 6.1 規則
- **三夜制**：一局三回合（稱「夜」），先拿下兩夜者勝。
- 開局抽 **10 張**，第二夜開始前 +2 張，第三夜前 +1 張；牌組 20–30 張。
- 每回合輪流**出一張牌或「熄燈」（pass）**。雙方都熄燈 → 該夜結算：場上總點數高者贏得該夜。熄燈後不能再出牌。
- 場地有三條**燈列**：**炬（近）**、**弓（遠）**、**咒（術）**。單位牌只能放在指定燈列。
- 每夜結束場上單位進入棄牌堆（除非有「餘燼」關鍵字：保留到下一夜，點數減半）。
- 出牌開始前可**換牌 2 張**（只限第一夜）。

### 6.2 牌的類型
- **單位**：有點數（1–10）與燈列；部分有能力。
- **天象（環境牌）**：影響一整列，例：「霧夜」：弓列所有單位點數變 1。「晴星」：清除所有天象。
- **術式（法術）**：一次性效果。
- **英雄牌**：不受天象和術式影響。每副牌最多 2 張。

### 6.3 關鍵字（原創）
| 關鍵字 | 效果 |
|---|---|
| 點燈 | 打出時，同列所有友方單位 +1 |
| 共鳴 | 同名卡在場上時，每張點數 ×2 |
| 餘燼 | 夜結束時保留在場上，點數減半（向下取整，至少 1） |
| 引燃 | 摧毀敵方該列點數最高的單位（若該列總點數 ≥ 10） |
| 召喚 | 打出時從牌組召喚所有同名卡 |
| 間諜 | 放在對手場上（點數算對手的），你抽 2 張 |
| 治癒 | 從棄牌堆打出一張非英雄單位 |
| 誘餌 | 0 點，可將場上一張我方單位收回手牌 |

### 6.4 陣營牌組（4 個，對應勢力）
- **星衛騎士團**：高點數、穩定、英雄多。
- **灰燈鎮民**：點燈、共鳴、數量取勝。
- **礦工公會**：引燃、天象（坑道粉塵）。
- **燼牌會（流浪商隊）**：間諜、誘餌、詐術。
- 玩家起始用灰燈鎮民牌組；可從商店、對戰勝利、探索取得新牌，**牌組可自由組合**（同陣營或中立牌）。

### 6.5 AI
- 規則式 AI，3 個難度：會評估「這夜還有沒有機會贏」決定熄燈；困難 AI 會留牌到第三夜、會打天象。
- 寫成**純 TypeScript 無頭模擬**，用 vitest 跑 1000 局測平衡（各陣營勝率 40–60%）。

### 6.6 與 RPG 的連結
- 酒館 NPC 對戰：贏得金錢、稀有牌、情報（攻略筆記條目）。
- 部分任務可以「用燼牌決勝負」替代戰鬥（例：用牌局贏回莉歐拉被押的發明）。
- 第 3 章王都燼牌大賽是一個小高潮。
- 卡牌收集圖鑑：全 60–80 張。

## 7. 數值框架（初版，會用模擬調整）
### 7.1 角色成長
```
HP(L)  = baseHP  × (1 + 0.12 × (L−1))
ATK(L) = baseATK × (1 + 0.10 × (L−1))
DEF(L) = baseDEF × (1 + 0.08 × (L−1))
```
| 角色 | baseHP | baseATK | baseDEF | SPD |
|---|---|---|---|---|
| 連恩 | 90 | 14 | 8 | 12 |
| 瑟琳 | 110 | 18 | 10 | 11 |
| 莉歐拉 | 75 | 12 | 6 | 13 |
| 伊歐 | 70 | 9 | 7 | 14 |
| 洛克 | 140 | 13 | 14 | 8 |

### 7.2 傷害公式
```
damage = max(1, round( ATK × skillMul × timingMul × elementMul × breakMul − DEF × 0.5 ) × rand(0.95,1.05))
timingMul: perfect 1.5 / good 1.15 / miss 0.85
elementMul: 弱點 1.5 / 抗性 0.5
breakMul: 破防中 1.5
```
### 7.3 經驗與節奏
- 從 L 升到 L+1 需要 `XP = 40 × L^1.6`；每隻雜魚給 ≈ 敵人等級 × 6 XP，Boss ≈ ×24（詳見 09）。
- 目標：每區域結束時，玩家大約 = 區域推薦等級 + 1（不刷也能過；探索完整的玩家略有優勢）。
- 敵人數值由「區域等級」生成：`enemyHP = 30 × 1.18^(lv)`，`enemyATK = 8 × 1.12^(lv)`，由模擬校準。

### 7.4 平衡驗證
- `src/core/sim/`：戰鬥模擬器（純邏輯），對時機輸入用機率模型（新手：30% perfect / 50% good；高手：70% / 25%）。
- 目標：新手玩家打雜魚勝率 > 95%、Boss 首戰勝率 50–70%；高手 Boss 首戰 > 90%。
