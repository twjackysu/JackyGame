# 07 UI / UX 線框

> 座標以設計解析度 720×1280 為準。拇指熱區 = y ≥ 820（下 1/3）。點擊目標 ≥ 88×88。
> 安全區：上方保留 60px（瀏海）、下方保留 40px（Home 指示條）。

## 0. 全域規範
- **字級**：標題 64–96、區塊標題 40、內文 30、次要 24（最小 22）。
- **按鈕**：圓角 18、面板色 `rgba(16,12,34,0.82)`、描邊琥珀 `#ffb34755`、按下縮 0.94 + `ui_tap`。
- **轉場**：場景切換用「燈熄滅」轉場：畫面從四角暗下收成一個光點 → 新場景從光點展開（300ms + 300ms）。
- **自動存檔指示**：右上角小提燈圖示亮 0.8 秒。
- **返回**：左上角 ← （88×88），Android 返回鍵對應同一動作。

- 點任意處：打字中 → 顯示全文；已完成 → 下一句。長按 = 快轉。
- **選擇**：對話框上方堆疊 2–4 個選項按鈕（寬 640、高 96）。檢定選項左側有標籤：
  - `[魅 6] 62%` 金色　`[筆記] 必定成功 ⟡偏移+5` 青色　`[戰鬥]` 紅色
- 擲骰演出：20 面星形骰旋轉 0.8 秒 → 成功（琥珀爆光）/ 失敗（灰色碎裂）。

## 7. 選單（MenuScene）
- 底部分頁列：**隊伍 / 裝備 / 道具 / 筆記 / 羈絆 / 設定**（6 個 icon，每個 120 寬）。
- **筆記**：書頁風格，分類標籤（敵人/寶藏/事件/命運），未解鎖顯示 `？？？`，偏移失準條目有 ⚠ 與雜訊效果。頂部顯示偏移值量表。
- **羈絆**：每位同伴一張卡（剪影 + 好感燈芯 0–5 盞 + 下一個事件提示）。
- **設定**：BGM、SFX 音量；自動時機開關；時機校準（點擊節拍測延遲）；畫質 高/低；文字速度；語言（繁中/English 預留）；刪除存檔。

## 8. 新手引導原則
- 不用彈窗教學。序章用「劇情中的指示」：教官喊「看準時機！」+ 光環慢速版。
- 每種新輸入第一次出現時遊戲**暫停**並用手指圖示示範，成功一次後繼續。
- 燼牌：洛克邊打邊講解；教學局腳本化兩夜制（見 09 §5）。
