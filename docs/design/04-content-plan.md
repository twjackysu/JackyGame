## 2. 序章：啟星儀式（P0，垂直切片開頭）
1. 黑畫面 + 前世獨白（3 句）→ 光芒 → 甦醒在儀式隊伍中。
2. 儀式：結晶判定「掌燈人」，全場嘲笑（演出：鏡頭掃過觀眾剪影 + 竊竊私語文字泡）。
3. 選擇：當眾反駁 `[魅 3]` / 隱忍 / `[筆記] 指出儀官的手腳`（偏移 +5）。
4. 被逐出 → 訓練場籠子的蝕化獸失控 → **教學戰**：攻擊時機、格擋、閃避。
5. 主角發動燈印 ×3 → 共鳴（強制演出教學，全畫面光柱）。秒殺。
6. 瑟琳看見了，但騎士團長說「意外」。主角離開，回灰燈鎮。

## 3. 第 1 章：灰燈鎮 + 霧語森林（P0 垂直切片主體）
### 節點地圖
`灰燈鎮廣場 ─ 酒館「醉燈」 ─ 雜貨店 ─ 孤兒院`
`鎮門 ─ 森林入口 ─ 獵人小屋 ─ 狼徑 ─ 古燈塔遺跡（傳承）─ 霧之湖（伊歐）─ 狼王巢穴（Boss）`

### 主線任務「掌燈人的傳承」
1. 孤兒院院長給主角舊提燈（羈絆起點）。
2. 攻略筆記：「古燈塔遺跡有掌燈人傳承，需要三枚燈芯」。
3. 收集燈芯 ×3：獵人小屋（說服或燼牌贏來）、狼徑（戰鬥）、霧之湖（調查/引路之光）。
4. 霧之湖：遇見伊歐（筆記查無此人 → 演出：筆記頁面出現雜訊）。伊歐加入。
5. 古燈塔：解鎖技能樹 + 主動技能「引路」。
6. Boss：**霧角狼王**（2 階段：第二階段召喚霧，弓列視野降低 → 必須用引路之光照亮）。

### 支線（P0 至少 2 支，P1 再加 2）
- **S1 迷路的商隊**（P0）：狼群包圍商隊 → 戰鬥救援 or 用引路之光引開狼群（智檢定）。救下後商隊在第 3 章出現（延遲後果）。
- **S2 酒館老千**（P0）：洛克在酒館用燼牌騙錢 → 跟他打一局（燼牌教學）→ 贏了得到稀有牌 + 洛克印象。
- **S3 孤兒院的屋頂**（P1）：收集材料修屋頂；完成後孤兒院孩子們在結局出現。
- **S4 獵人的誓言**（P1）：獵人想報狼王之仇，帶他去 Boss 戰（他會犧牲 or 被你說服留下）。

### 敵人（第 1 章）
| 敵人 | 等級 | 特色 | 弱點 |
|---|---|---|---|
| 霧狼 | 1–3 | 快，兩連擊（白光） | 火（燈） |
| 刺蕈 | 2 | 慢，毒孢子（紅光，需閃避） | 火 |
| 蝕化野豬 | 3–4 | 衝鋒（紅光）、蝕化（紫光） | 光 |
| 霧角狼王（Boss） | 5 | 2 階段、召霧、嚎叫增益 | 火、光；角是破防點 |

## 4. 第 2–5 章敵人與 Boss 概要（P1）
- 第 2 章 沉鐘礦坑：岩甲蟲、礦燈幽魂、爆炸蜥；Boss **鐘喉蠕蟲**（鐘聲節奏 → 格擋節拍挑戰）。
- 第 3 章 星冠城：騎士團叛徒、研究院機兵、刺客；Boss **洛克**（可透過 3 段說服跳過戰鬥）。
- 第 4 章 研究院：蝕化兵器原型、星燼魔像；Boss **大司星瓦爾德蘭**（3 階段，會「抄襲」你的燈印）。
- 終章：**蝕之王**（4 階段，最終階段伊歐回溯能力的劇情化運用）。

## 5. 燼牌內容
- P0：灰燈鎮民牌組 20 張 + 對手「洛克（燼牌會）」牌組 20 張，共 ~30 種卡。
- P1：4 陣營完整，共 60 種卡；6 位酒館對手；王都大賽（3 連戰）。
- P2：卡牌圖鑑全收集獎勵（特別卡背）。

## 8. 「好玩嗎？」檢查點
每完成一塊用這張表自問（結果記錄在 PROGRESS）：
1. 開場 60 秒內有沒有讓人「哇」的瞬間？
2. 每一場戰鬥有沒有至少一個需要判斷的時刻？
3. 玩家是否明確知道下一步要去哪？
4. 每 5 分鐘內有沒有新的東西（台詞、獎勵、演出）？
5. 選擇有沒有讓人猶豫？
