## 2. 序章：被留下的燈（P0，垂直切片開頭）
1. **冷開場（15 秒，0 操作也很帥）**：前世手機畫面框內，最終 Boss 戰的 5 盞燈印共鳴全演出 →「全成就達成」→ 手機掉落、畫面熄滅。
2. 甦醒在遺跡迴廊，手上提著燈，前方是騎士團遠征隊。3–4 句對話交代身分。
3. 隊長葛文嫌掌燈人拖慢進度，把連恩踢出隊伍、留下來「看守退路」（其實是當誘餌）。選擇：`[魅 3]` 頂撞 / 隱忍 / `[筆記]` 揭穿隊長私吞遺物（偏移 +5）。
4. 蝕化獸從牆中爬出 → **教學戰**：攻擊時機、格擋、閃避。
5. 主角發動燈印 ×3 → 共鳴（教學戰開始時星燼直接給滿 10，強制演出，全畫面光柱）。秒殺。
6. 回頭找他的瑟琳目擊；隊長說是「遺跡機關誤觸」。連恩被正式解雇，回灰燈鎮。

## 3. 第 1 章：灰燈鎮 + 霧語森林（P0 垂直切片主體）
### 節點地圖（照劇情順序由近到遠，不走回頭路）
`孤兒院 ─ 灰燈鎮廣場 ─ 酒館「醉燈」／雜貨店 ─ 鎮門`
`鎮門 ─ 森林入口（S1 商隊）─ 霧之湖（伊歐、燈芯）─ 獵人小屋（燈芯）─ 狼徑（燈芯）─ 古燈塔遺跡（傳承）─ 林間營火 ─ 狼王巢穴（Boss）`
- 隱藏節點：狼王巢穴旁「倒木下的寶箱」（提燈之光揭露，霧之墜飾）。

### 隊伍變化
- 1-2 酒館之後：**洛克以客座身分同行**（「商隊欠我錢，我順路去森林討債」），可操作，到狼王戰結束後前往王都暫別。→ 第 1 章大半就有 2 人隊伍，並建立洛克羈絆。
- 1-5 霧之湖：**伊歐加入**。之後 3 人隊伍（連恩、洛克、伊歐）。

### 主線任務「掌燈人的傳承」
1. 孤兒院院長給主角舊提燈（羈絆起點）。
2. 攻略筆記：「古燈塔遺跡有掌燈人傳承，需要三枚燈芯」。
3. 收集燈芯 ×3：霧之湖（伊歐指出位置）、獵人小屋（說服 / 燼牌 / 幫他清狼徑）、狼徑祠堂（戰鬥：蝕化野豬）。
4. 霧之湖：遇見伊歐（筆記查無此人 → 演出：筆記頁面出現雜訊）。
5. 古燈塔：解鎖戰鬥技能「引路之光」（可抵消紫光）。
6. Boss：**霧角狼王**（2 階段：第二階段召喚濃霧 → 畫面變暗、時機光環變淡且判定窗口縮小 30%；狼王的「霧襲」是紫光 → 必須用剛學會的引路之光。身上的燈印在霧中發光，讓玩家看得到牠）。

### 支線（P0 至少 2 支，P1 再加 2）
- **S1 迷路的商隊**（P0）：狼群包圍商隊 → 戰鬥救援 / 用提燈之光引開狼群（智檢定）/ 筆記 / **不管他們繼續趕路**。當章回饋：救下 → 送燼牌包 + 商店多一個商人；不管 → 之後在森林撿到翻倒的馬車殘骸與一封信（罪惡感台詞），洛克好感 −5。延遲後果：第 3 章王都。
- **S2 酒館老千**（P0）：洛克在酒館用燼牌騙錢 → 跟他打一局（燼牌教學，腳本化兩夜制）→ 贏了得到傳說牌 + 洛克好感。
- **S3 孤兒院的屋頂**（P1）：收集材料修屋頂；完成後孤兒院孩子們在結局出現。
- **S4 獵人的誓言**（P1）：獵人想報狼王之仇，帶他去 Boss 戰（他會犧牲 or 被你說服留下）。

### 敵人（第 1 章）
| 敵人 | 等級 | 特色 | 弱點 |

| 霧狼 | 2 | 快，兩連擊（白光） | 火（燈） |

## 4. 第 2–4 章與終章敵人與 Boss 概要（P1）
- 第 2 章 沉鐘礦坑：岩甲蟲、礦燈幽魂、爆炸蜥；Boss **鐘喉蠕蟲**（鐘聲節奏 → 格擋節拍挑戰）。
- 第 3 章 星冠城：騎士團叛徒、研究院機兵、刺客；Boss **洛克**（可透過 3 段說服跳過戰鬥）。
- 第 4 章 研究院：蝕化兵器原型、星燼魔像；Boss **大司星瓦爾德蘭**（3 階段，會「抄襲」你的燈印）。
- 終章：**蝕星者**（4 階段，最終階段伊歐回溯能力的劇情化運用）。

## 5. 燼牌內容
- P0：灰燈鎮民 + 燼牌會兩陣營，約 26 種卡（見 09）；對手：洛克（教學）、伯恩、酒館常客 1 人。

## 8. 「好玩嗎？」檢查點
每完成一塊用這張表自問（結果記錄在 PROGRESS）：
1. 開場 60 秒內有沒有讓人「哇」的瞬間？
2. 每一場戰鬥有沒有至少一個需要判斷的時刻？
3. 玩家是否明確知道下一步要去哪？
4. 每 5 分鐘內有沒有新的東西（台詞、獎勵、演出）？
5. 選擇有沒有讓人猶豫？
