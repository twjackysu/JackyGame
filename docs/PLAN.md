## 目標（第二期）
**2026-11-13 12:00（台北）**前，在 1.1.0 的基礎上交出 1.2.0：
1. **程式品質**：確定性加固、統一存檔層、規則下沉到核心、效能熱點改善、拆掉 6,500 行的 `RtBattleScene`。
2. **單機模擬線上版**（D-277，規格 `docs/design/24-online-architecture.md`）：遊戲內建本機伺服器（權威）＋本機資料庫，客戶端只透過 JSON 訊息呼叫；之後**只換資料庫或後端**就能上線。
3. **新功能（交易、PvP 為主）**：多角色＋共用倉庫、拍賣所＋模擬玩家、託管交易、PvP 競技場天梯（伺服器重跑驗證勝負）、對戰重播。
4. **美術**：星隕高原怪物與各地圖狼的 AI 圖、動態光照、天氣氛圍、UI 外框。

完整內容與驗收條件：**`docs/design/23-v2-roadmap.md`**（主線，每輪照它選工作）。
