# 星燼回響 Echoes of Starfall

> 前世是冷門手遊的全成就玩家，轉生進那款遊戲的世界——他記得森林裡哪裡藏著寶箱、狼王撞上岩壁會暈、連續打倒幾群狼就會引出首領。

原創冒險 RPG，手機單機（iOS / Android / PWA），**完全離線**、直式單手操作、單人即時動作戰鬥。

🚧 **開發中**（2026-10-23 開工，11/05 成果發表）。進度見 [`docs/PROGRESS.md`](docs/PROGRESS.md)，計畫見 [`docs/PLAN.md`](docs/PLAN.md)。

## 三張大地圖：霧語森林・荊棘谷・燼紅裂谷
- **一整張可以自由走的森林**（48×96 格、六個地區），整張地圖就是一場即時戰鬥：走過去、狼看到你就醒、直接開打，沒有切換戰鬥畫面，也沒有時間限制。
- **簡單但吃技巧**：左下搖桿或點地面移動，放開就自動追擊＋普攻；右下重斬、旋風斬、衝鋒、格擋反擊、閃避，打出傷害集滿 MP 放大招「劍刃風暴」。敵人出手前地上會出現紅色範圍，**由內往外填滿就命中**；黃框的攻擊可以格擋反擊。
- **越深越兇、也掉得越多**：南營地 → 森林入口 → 狼群巢穴／森林深處 → 精英狼群 → **霧角狼王**（兩階段、衝鋒撞岩壁會暈）。狼王打倒後離開巢穴會回來，可以一直挑戰、刷最快紀錄。
- **越刷越強**：打怪得經驗、升級立刻變強；怪物會掉**裝備**（6 格：武器、頭盔、鎧甲、護手、戒指、項鍊；普通／精良／稀有，精良以上地上有光柱、帶隨機詞綴；稀有一定帶、精良偶爾帶（數值減半）「重斬冷卻 −12%」「旋風斬範圍 +25%」「格擋判定 +0.1 秒」這類技能特效）。在「行囊」看「換上後攻擊 +12・HP +80」再決定；用不到的分解成粉塵，**在營火旁強化 +1～+10**；每次進森林第一次打倒狼王保底稀有。實測普通 Bot 刷 30 分鐘後，同一隻狼王從約 170 秒打到約 90 秒。
- **暴怒狼王**（Lv8 或討伐 3 次解鎖，☰ 開關）：HP、攻擊大增、出招更快，還有專屬招式——**遁入霧中瞬移到你背後撕咬**、**衝鋒完立刻回頭再衝一次**；一次掉 3 件、物品等級更高、稀有 70%。
- **荊棘母樹**：精英狼群區東側一棵不會動的世界精英，遠處射毒刺、中距離根系環（貼著樹反而安全）、貼身大橫掃；4 分鐘重生，必掉兩件精良以上，適合刷裝。
- **深夜的森林**（打倒暴怒狼王解鎖）：同一張森林只剩主角身邊的光，狼群更兇、掉得更多更好，還有深夜才出現的精英「霧影狼」、遠處就看得到的**夜光寶箱**（每次進深夜都補滿），深夜掉的稀有裝備多一條詞綴（「夜燼・」）。
- **第二張地圖「荊棘谷」**（在霧語森林打倒狼王一次後開放，標題或 ☰ 直接前往）：一條蜿蜒的山谷（48×80），紅褐乾土、整片紫紅荊棘叢；**等級、行囊、技能點與材料和霧語森林共用**。帶毒的**棘背狼**、站進去會一直中毒的**綠色毒沼**（東邊寶箱就泡在毒沼裡）、母樹空地的荊棘母樹、棘刺迴廊的首領與射手，最後是 Boss **棘冠狼后**——爪擊、八格毒刺、根系環、衝鋒，半血後招喚棘背狼、放「荊棘綻放」大圈；暴怒版還會**毒刺連射**、**鑽進荊棘從背後冒出來**。荊棘谷掉的裝備物品等級更高，稀有叫「荊冠」。也有暴怒狼后與深夜的山谷。
- **第三張地圖「燼紅裂谷」**（在荊棘谷打倒狼后一次後開放，建議 Lv10）：黑色玄武岩高地、岩壁上發光的熔岩裂紋。地上的**熔岩口會輪流噴發**——噴發前地面越來越亮、外圈收縮，可以看準空檔穿過、用閃避的無敵躲掉，也可以**把追著你的怪引過去燒**（算你的擊殺）。南邊岔路自由選：西邊「噴口原」近但要看噴發時機、東邊「黑曜長廊」遠但有精英「黑曜首領」守著寶箱。新怪：會跳過來壓人的**熔渣史萊姆**、咬兩下的**燼鬃狼**、射熔岩彈的**燼芯菇**；Boss **燼心岩王**——拳擊、十格熔岩裂地、重踏，半血後震波環＋招喚史萊姆，命中的地方會**裂出熔岩紋**，王座邊緣的熔岩口也會噴；暴怒版多一招超大範圍的「**熔心爆發**」。深夜的裂谷熔岩口噴得更頻繁，熔渣坡還有背著火焰鬃毛的巡邏精英「**熔核巡者**」。稀有裝備叫「燼心」。
- **會巡邏的世界精英**：荊棘谷的**荊棘巡獵者**在棘刺迴廊西側來回走，地上畫出牠的**橘色仇恨圈與視線扇形**、走過留下腳印——可以等牠走開再過，也可以正面迎戰（必掉精良以上）；牠不會追進狼后的地盤。霧語森林白天就有**迷霧巡守**在精英狼群區西側繞圈（守著西北角的寶箱，青色視線圈），交戰中會**隱入霧中、從你背後撲出來**；深夜的森林裡，**霧影狼**也在南林東側巡邏。
- **自由搭配技能**：每升一級得 1 技能點，自由點在重斬、旋風斬、衝鋒、格擋反擊、劍刃風暴上（傷害、範圍、冷卻、格擋判定…），和裝備特效相加，隨時免費重置。技能**滿 5 級可以切換「變化」**——同一顆按鈕換一種招式：裂地斬（直線穿透劍氣）、龍捲（邊轉邊全速移動）、流星衝（衝 6 格落地爆炸）、不動架勢（長窗口、全方位反擊）、星落一閃（天降光柱一擊）。每個技能還有**第二種變化**（「原招 → 變化 → 變化二」輪流切換），而且帶狀態：碎甲斬（破甲、更容易被爆擊）、霜旋（小怪冰凍、Boss 減速）、影步（快速短衝、敵人虛弱）、迴光一閃（0.3 秒極短窗口、擋下反擊 6 格劍氣 420%）、破空斬月（前方 8 格長劍氣＋破甲，蓄力時自動對準目標、畫出瞄準線）。
- **營火行商「旅商莫托」**（就站在營火旁，提著燈、背著大背包）：撿到的金幣終於能花——營火旁點「行商」就能**自由買賣**：貨架上 3 件精良＋1 件稀有（物品等級跟著你的等級、每次進地圖換一批，也可以花 40 金立刻換貨）、粉塵與結晶隨時買；每批貨的稀有那件是「**為你挑選**」——旅商看你身上哪一格最弱就帶那個部位（物品等級再高一級），還會直接說「護手該換了吧？」。背包裡用不到的裝備可以賣錢，一鍵賣掉所有普通裝。刷 30 分鐘大約買得起一件稀有＋兩件精良，最好的裝備還是要去打 Boss。
- **營火燼牌**（卡牌小遊戲）：行商面板的「燼牌」分頁，坐下來和旅商莫托打一場**三局兩勝**的牌——雙方各抽 10 張、整場不補牌，輪流把牌放到前排或後排，總點數高的贏一局；覺得夠了就「放棄這一局」把牌留到下一局，**什麼時候收手**是勝負關鍵。牌有同袍（同名越多越強）、斥候（送給對手、換你抽 2 張）、戰號（一排 ×2）、霜寒／濃霧／晴空（天候）、傳奇（不受影響）。可以下注 40 金（贏了拿 80，還會**贏到莫托的一張牌**加進你的牌組，共 5 張）或只練習。
- **會呼吸的地圖**：森林裡飄著光塵、深夜有螢火蟲；荊棘谷落下紫紅花瓣與孢子；燼紅裂谷往上竄著火星、落著灰燼。把追你的怪引進熔岩口燒死會跳「燒死了！×N」。第一次開放新地圖時，標題的地圖按鈕會亮起金框和「NEW」。
- **Boss 登場與荊棘演出**：第一次和狼王／狼后交手時上下黑邊、世界壓暗、名牌滑入；狼后與荊棘母樹的毒刺、根系環、荊棘綻放命中時，**地面會真的長出紫紅荊棘**，Boss 倒下時荊棘一起枯萎。深夜的山谷毒沼會擴散，荊棘坡與迴廊還會多冒兩灘。
- **營地懸賞**：同時掛 3 張「打倒 X 隻 Y」，完成自動領粉塵／結晶，再換一張新的——每次進森林都有短短的目標。
- **營火**：怪不追進火堆旁；點營火休息回滿、補藥水；倒下會在營火醒來；營火旁可以直接開行囊、強化、找行商。
- **遊戲記憶**：靠近隱藏寶箱會浮現「這個地方似乎有點熟悉……」；不倒下連殺 12 隻會引出隱藏首領；偶爾會有狼群暴動。
- **紀錄**：等級、行囊、累計擊殺與材料、開過的寶箱、狼王討伐次數與最快時間，自動存在手機上。
- **操作自訂**：拖曳調整每顆按鈕與搖桿的位置、交換技能欄、左手模式、按鈕大小、桌機改鍵（☰ → 操作設定）。

## 怎麼玩
- **PWA（任何手機瀏覽器）**：https://twjackysu.github.io/JackyGame/ 
  - iOS Safari：分享 → 加入主畫面；Android Chrome：選單 → 安裝應用程式。之後可離線遊玩。
- **Android APK**：[Releases → latest](https://github.com/twjackysu/JackyGame/releases/tag/latest) 下載 `jackygame-debug.apk`，允許「安裝未知來源應用程式」後安裝。
- **iOS（原生，需 Mac）**：
  1. 安裝 Xcode、Node 22+。
  2. `npm ci && npm run build && npx cap sync ios && npx cap open ios`
  3. Xcode → Signing & Capabilities → Team 選你的（免費）Apple ID，Bundle ID 若衝突就改一個。
  4. 接上 iPhone，按 ▶︎ 執行。iPhone 上到「設定 → 一般 → VPN 與裝置管理」信任開發者。免費帳號簽署 7 天有效。
- 開發用試玩小關卡：`?debug&scene=RtBattle&stage=wolf_king`（`forest_entry`／`wolf_den`／`forest_deep`／`elite_pack`／`rock_grove`／`camp_clearing`，☰ 可換關；加 `&bot=expert` 看 Bot 自己打）。

## 開發
```bash
npm ci            # 需 Node 22.12+
npm run dev       # 開發伺服器
npm test          # vitest
npm run build     # typecheck + 產出 dist/
npm run sim:rt    # 即時戰鬥無畫面模擬報表
```
技術：TypeScript、Vite、Phaser 3、vite-plugin-pwa、Capacitor 8。戰鬥核心是純 TypeScript（`src/core/battle/rt/`，30 ticks/秒、可重現），畫面層在 `src/game/`。
